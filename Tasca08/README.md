# 🏗️ Introducció a la tasca: Auditoria i Estandardització del Servidor Base

Benvinguts, equip! 👋

Durant les últimes setmanes hem implementat serveis avançats per als nostres clients, com ara servidors de fitxers (NFS), impressió (CUPS) o autenticació (LDAP). Però cap d’aquests serveis pot funcionar de manera fiable si els fonaments del sistema operatiu no són completament sòlids.

Un servidor amb una configuració de xarxa incorrecta, permisos mal assignats o paquets sense actualitzar representa un risc crític de seguretat i una futura incidència garantida ⚠️. A **EverPia**, la nostra reputació es basa en la robustesa, l'estabilitat i la qualitat mil·limètrica de cada desplegament.

### 🎯 Missió: Auditoria i Estandardització del Servidor Base

Abans de procedir al desplegament de serveis avançats, durem a terme una auditoria interna i aplicarem de manera rigorosa el nostre **Protocol de Desplegament Estàndard (SOP - Standard Operating Procedure)**. 

L’objectiu d'aquesta línia de treball és demostrar que som capaços de:
* **Desplegar** una nova màquina virtual Ubuntu Server des de zero 🖥️.
* **Aplicar** el protocol de configuració bàsica recollit al SOP (gestió de xarxa, usuaris, actualitzacions i seguretat).
* **Consolidar** una infraestructura base totalment sòlida abans d’intervenir en l’entorn de producció dels clients ✅.

Aquesta fase d’entrenament està dissenyada per preparar els consultors juniors, garantint que dominin les tasques essencials d'administració de sistemes de manera nativa.

### 🛠️ Fase d’entrenament

Per a la realització de les proves de concepte, s'utilitzarà l’arxiu OVA disponible a l'entorn de pràctiques per executar de manera seqüencial les tasques indicades al document oficial `Projecte4-TascaSOP`. 

*Nota: Tot i que aquesta fase no requereix el lliurament formal de cap activitat, és crucial comprendre el funcionament intern de cada paràmetre i comanda de cara a la validació tècnica final.*

### 🏅 Certificació SOP Specialist

Una vegada finalitzat el període d’entrenament, s'haurà de superar un examen pràctic altament exigent que validarà els coneixements adquirits en un entorn real:
* La prova es realitzarà sota condicions específiques (només es permetrà l'ús d'un full manuscrit amb anotacions personals).
* L’objectiu final és certificar la competència completa de l'operador en matèria de configuració bàsica, securització i auditoria de servidors corporatius.
